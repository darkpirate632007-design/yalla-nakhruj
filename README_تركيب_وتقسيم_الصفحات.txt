يلا نخرج — نسخة ReactJS متعددة الصفحات
======================================

هذه نسخة من مشروعك بعد تقسيم الواجهة إلى ملفات مستقلة، مع الحفاظ على منطق البحث والخريطة والمفضلة وتقييمات الأماكن وخطة الخروجة واللغة المحفوظة.

هيكل الملفات الجديد
-------------------
src/App.jsx                         إدارة الحالة ووظائف الموقع والتنقل
src/AppContext.jsx                  مشاركة الحالة والوظائف بين الصفحات
src/pages/HomePage.jsx              الصفحة الرئيسية
src/pages/ExplorePage.jsx            اختيار التصنيف وعرض الأماكن والبحث والخريطة
src/pages/OutingPlannerPage.jsx      صفحة خطة الخروجة
src/components/Navbar.jsx             شريط التنقل واللغة والتثبيت
src/components/PlaceDetailsModal.jsx  تفاصيل المكان
src/components/CountryPickerModal.jsx اختيار الدولة
src/components/MapController.jsx      التحكم في عرض الخريطة

التنقل بين الصفحات
------------------
المشروع يستخدم hash-based routing حتى تكون روابط الصفحات مناسبة للنشر على GitHub Pages دون إضافة مكتبة توجيه جديدة:
#/home
#/places
#/favorites
#/outing
#/details

خطوات التركيب
-------------
1. خدي نسخة احتياطية من فولدر مشروعك الحالي أولًا.
2. فكّي ضغط هذه الحزمة داخل فولدر نسخة المشروع الاحتياطية/الجديدة، أو فكّيها فوق مشروعك بعد أخذ نسخة احتياطية. وافقي على استبدال الملفات المتطابقة.
3. الملفات الجديدة داخل src/pages وsrc/components وsrc/AppContext.jsx ضرورية؛ لا تنقلي App.jsx وحده.
4. افتحي Terminal داخل فولدر المشروع. إذا كانت node_modules موجودة عندك أصلًا، لا تحتاجين تثبيتها مرة أخرى. شغّلي:
   npm run build
   npm run dev
5. إذا كان المشروع في فولدر جديد ولا يحتوي على node_modules، شغّلي أولًا npm ci، ثم npm run dev.

ملاحظات
-------
- الحزمة لا تتضمن node_modules أو dist؛ يتم إنشاء dist عند تشغيل npm run build.
- لم أضف react-router-dom؛ التنقل داخلي باستخدام hash حتى لا نحتاج تثبيت dependency إضافية.
- ملف src/.env لم يتم تضمينه لأن النسخة المرفوعة كانت تحتوي على مفتاح API. الكود الحالي لا يقرأ VITE_GEOAPIFY_API_KEY، لذلك ليس مطلوبًا لتشغيل البحث الحالي. عند فك الحزمة فوق مشروعك الأصلي، لن تستبدل ملف .env المحلي الموجود؛ احتفظي به محليًا إن احتجتيه، ولا ترفعيه إلى GitHub.
- تم فحص صياغة ملفات JavaScript/JSX والتأكد من وجود مسارات الاستيراد المحلية. تعذّر تشغيل build في بيئة التجهيز لأن الاتصال بـ npm registry فشل؛ نفّذي npm run build على جهازك للتأكد من التكامل النهائي.
